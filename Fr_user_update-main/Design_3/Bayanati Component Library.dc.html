Bayanati · component library v2 · one-time account data update
مكتبة مكوّنات بيــانــاتــي
Arabic-first, RTL, one journey of twelve stages completed once per account. No dashboard, no tab bar, no repeat visits — every screen is a step, and the only navigation is forward, back, or abandon. White surfaces, hairline boundaries, square corners; navy is reserved for the brand moments (launch, stage header, confirmation).

letter-spacing 0 everywhere (positive tracking breaks Arabic joins), body never below 16, helper never below 14, no italic — carried over from app_theme.dart. Amiri is the splash face only — the launch screen, Arabic only. Every other surface, including the confirmation, is IBM Plex Sans Arabic. Latin labels use IBM Plex Sans Condensed, the matching member of the same superfamily. Numerals follow the repo's existing rules — customers may TYPE Arabic-Indic digits and ArabicDigitInputFormatter transliterates them to ASCII before anything is sent; everything DISPLAYED is Latin digits, tabular, and direction-isolated (LtrValue for a standalone value, FSI/PDI when interpolated into an Arabic sentence). Dates display as DD/MM/YYYY, never ISO (display_date.dart).
