Messages and end states.

```jsx
<Banner tone="warn">بعد الإرسال لا يمكن التعديل من التطبيق.</Banner>
<OfflineBanner />
```

- `OfflineBanner` is pinned under the header on every journey screen and carries a fixed string — do not reword it.
- `Tag` carries field provenance on review rows: السجل المدني (accent), المسح (neutral), إدخال العميل (neutral).
- `TerminalState` is white on every end state except the confirmation, which is the one navy moment besides launch.
