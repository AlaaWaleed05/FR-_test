# Source material — not authoritative

This directory holds raw material supplied by the bank and by the product owner during
planning. **Nothing here is authoritative.** The authoritative artefacts are
`docs/reference/` for reference data and `docs/journeys/` for the specification.

- `Sudan_Admin_Hierarchy.xlsx` and `Sudan_States_and_Localities.xlsx` are **superseded
  drafts**. The current dataset is `docs/reference/NSudan_Admin_Hierarchy.xlsx`, itself
  interim per OQ-012.
- `إدارة الإلتزام.pdf` and the two WhatsApp photographs are the source the specification
  was derived from. They are kept here for provenance only.
